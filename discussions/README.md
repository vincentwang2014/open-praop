# Discussions

Anyone can challenge:

- a case's classification
- a pattern
- a practice
- a promotion decision

No formal committee is required for this in v0.1 (§17 of the protocol).
Open an Issue or PR comment describing what you think is wrong and why.
Practices submitted without an evidence link also start here rather than
going straight into `../practices/` (§14 of the protocol).

If your challenge is really a new case (something actually happened that
contradicts an existing pattern), submit it as a Case instead — see
`../cases/TEMPLATE.md`. A pattern's Status can move to `Contested`
without anyone needing to resolve the disagreement immediately; see §9
of the protocol.
