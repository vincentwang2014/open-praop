# Playbooks

A Playbook answers: **how does a team combine several Practices into a
daily workflow?**

v0.1 doesn't pursue playbook volume — just the format. See
`TEMPLATE.md`. No playbooks exist yet; there's only one practice so far
(`../practices/mid-run-issue-gate.md`), and a playbook combining
practices that don't exist yet would be exactly the kind of
premature-structure this project is trying to avoid (§18, Control
Accretion).

A playbook belongs here once at least two related practices exist with
some track record, not before.
