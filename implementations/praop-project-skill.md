# PRAOP Project Skill

The PRAOP Project Skill applies Open PRAOP practices inside live
AI-assisted projects.

It provides a lightweight project handoff structure built around:

- Project Report
- Development Memory
- Lessons Learned
- Tomorrow

Session-start and session-end behavior — what to read, what to update,
what *not* to update, and the EDTCU plain-language check before anything
gets saved as a lesson — is defined in the skill itself, not duplicated
here.

**Repository:** https://github.com/vincentwang2014/praop-project-skill

**Status:** Observed / Active — validated on one project, not yet a
second. See the repo's own README for current status.

> Open PRAOP defines the practice. PRAOP Project Skill implements it.
