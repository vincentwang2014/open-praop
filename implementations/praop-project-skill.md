# PRAOP Project Skill

The PRAOP Project Skill applies Open PRAOP practices inside live
AI-assisted projects. It has two layers:

- **Layer 1 — PRAOP Operating Kernel.** A short, ten-rule kernel for how
  to think and act *during* the work itself: treat AI output as
  probabilistic, prefer artifacts over memory, separate observation from
  interpretation as you go, reopen assumptions reality disagrees with,
  treat verification as part of completion, and don't let controls —
  including the kernel's own PRAOP-awareness — compound into ceremony.
- **Layer 2 — Project Memory / Handoff.** A lightweight project handoff
  structure built around:
  - Project Report
  - Development Memory
  - Lessons Learned
  - Tomorrow

Layer 2 alone is recording discipline, not PRAOP awareness — that's why
the kernel exists. Full session-start and session-end behavior — what to
read, what to update, what *not* to update, and the EDTCU plain-language
check before anything gets saved as a lesson — is defined in the skill
itself, not duplicated here.

**Repository:** https://github.com/vincentwang2014/praop-project-skill

**Status:** Observed / Active — validated on one project. Pilot 001 (a
second, independent project and agent) is in progress. See the repo's
own README for current status.

> Open PRAOP defines the practice. PRAOP Project Skill implements it.
