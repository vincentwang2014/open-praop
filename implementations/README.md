# Implementations

Open PRAOP defines the practice — cases, patterns, practices, playbooks,
protocol. This directory points to companion projects that put the
practice to work inside real AI-assisted projects.

**Rule: a canonical asset has exactly one home.** These are pointer
files, not copies. If a companion tool's `SKILL.md` (or equivalent) were
duplicated in here, one copy would drift from the other within months —
the exact semantic-drift failure this whole methodology exists to catch.
So each file below stays short: what the tool does, why it exists, and
where the actual, current version lives.

Naming convention for anything in the wider PRAOP ecosystem: `praop-*`
— so a new companion tool is recognizable as part of the same family on
sight.
