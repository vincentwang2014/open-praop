# Practice Template

Copy this file, fill it in, remove these instructions. A practice must
trace to at least one case — if you don't have one yet, this belongs in
`../discussions/` instead.

## Practice Title

One sentence describing what to do.

### Problem Addressed

What failure shape (or pattern) is this trying to reduce?

### When to Use

What environment or task does this apply to?

### What to Do

Must be an executable action, not a general aspiration.

### What Not to Do

Common misuses of this practice.

### Evidence

List the cases supporting this practice, e.g.:

- Case 014
- Case 022
- External Case 008

### Known Limitations

When would this not work?

### Enforcement Level

Pick one:

**Guidance** — relies on a person or agent choosing to follow it.

**Process** — already part of an explicit workflow.

**Mechanical Enforcement** — a tool, preflight, or gate blocks obvious
violations.

### Confidence

See §9 of the protocol — Confidence and Status are tracked separately,
e.g. `Operational / Active` or `Emerging / Contested`. A new practice
does not start at `Canonical`.
