# Practices

A Practice answers: **given a problem with some evidence behind it, what
can we actually do about it?**

A practice must trace back to a case or other evidence (§5 of the
protocol). No evidence link → it belongs in `../discussions/`, not here.
"Improve governance" is not a practice; "on finding a mid-run issue, ask
whether it invalidates the current run before deciding to fix it" is.

Each practice records its **Enforcement Level** honestly:

- **Guidance** — relies on a person or agent choosing to follow it.
- **Process** — built into an explicit workflow.
- **Mechanical Enforcement** — a tool, preflight check, or gate blocks
  the violation.

Don't claim Process or Mechanical Enforcement for something that's
actually just Guidance — that's exactly the "Knowledge Is Not
Enforcement" gap §3 of the protocol warns about.
